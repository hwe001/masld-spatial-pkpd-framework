# Human spatial profile inputs

`weiss_healthy_transporter_profiles.csv` is a small, auditable derivative of
the processed healthy-human scDVP results from Weiss et al., *Nature
Metabolism* (2026), PXD062231. The source coefficients are copied from
`results/human_controls/results_1_cutoff=0.7.tsv` in the authors' public
dashboard repository. The four model-zone values are generated by
`exp(coefficient * central_to_portal_position)` and normalized to mean one.

This is a protein-abundance profile, not a measured functional transporter
capacity. The model therefore uses these values only to define spatial
placement while holding mean capacity constant in the zonated versus
well-mixed comparison. Disease-state profiles remain hypothesis profiles.

Sources:

- https://doi.org/10.1038/s42255-026-01459-2
- https://github.com/BorgwardtLab/Human_scDVP_data_dashboard
- https://www.ebi.ac.uk/pride/archive/projects/PXD062231
